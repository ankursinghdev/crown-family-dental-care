## Tech

Plain HTML/CSS/JS — no build step. Open `index.html` in a browser, or serve statically:

```
python -m http.server 8000
```

Deployable as-is to GitHub Pages, Netlify, Vercel, or any static host.

## Features

- Responsive single-page layout (hero, about, services, why-us, reviews, contact)
- Real Google review quotes and rating
- WhatsApp appointment request form + floating WhatsApp button
- Click-to-call phone links and embedded Google Map
- SEO: meta tags, Open Graph, and LocalBusiness (Dentist) JSON-LD schema
